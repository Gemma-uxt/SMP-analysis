③ 계산 방법
  1. 올해 시간별 실적에서 '순부하(계통수요 − 시장 태양광·풍력)'와 SMP의 관계를 달마다 구함 — 같은 달, 순부하가 비슷한 40개 시간의 평균 SMP
  2. 연도별 설비가 올해의 몇 배인지 계산해, 시간마다 태양광 출력(시장·PPA·자가용)을 그만큼 늘림
  3. 늘어난 태양광만큼 순부하를 낮춰 ①의 관계로 SMP를 다시 구함
  4. 순부하가 올해 최저(26.1GW)보다 낮아지는 시간은 그만큼 태양광 출력제어로 처리
